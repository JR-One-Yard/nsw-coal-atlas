# Open the simplified NSW Coal Atlas

Double-click `launch.command` in this folder. Keep the server window open while viewing.

The map opens immediately. Choose a region at the top. The map opens with all 35 registry mines framed and translucent borehole depth lines visible. Select a compiled log trace to inspect its record. Use Layers for rock units, mine markers and borehole log visibility; Cross-section for a section through the model. Mines opens the statewide list. About contains sources and downloads.

The latest map and depth-line changes are available locally. The v3 ZIP contains an earlier interface and has not been refreshed with this increment. The existing private website has not been updated because the current Sites connection cannot find its saved project.

Read `docs/UI-HANDOVER.md` for completed work, workarounds, remaining decisions and verification evidence.
